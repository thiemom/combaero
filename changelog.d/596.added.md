- **The GUI auto-saves the network to the browser (#596).** Every change
  (nodes, edges, solver settings) writes the same JSON the Save button
  produces, minus solve results, to `localStorage`, debounced to 1 s. A
  reload restores it through the file loader, with a note "Restored your
  last session (autosaved HH:MM)". A new Clear button (trash icon, next to
  Load) empties the canvas and deletes the saved copy, after a confirmation.
  The copy is local to that browser: Save/Load remain the way to keep or
  share a network. A blocked or full storage never breaks the editor.
