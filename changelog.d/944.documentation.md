- **`dewpoint`'s RH range documented (#944).** RH in (0, 1]; RH = 1 returns the dry-bulb T; a supersaturated RH > 1 raises `RuntimeError` (the vapour-pressure step refuses it before the dewpoint solve, which is clamped to T and would otherwise return T); RH <= 0 or non-finite raises `ValueError`. In the C++ header, the binding's docstring, `docs/API_CPP.md` and `docs/API_PYTHON.md`; no behaviour change.
